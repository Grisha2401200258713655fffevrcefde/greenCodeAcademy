# Green Code Academy

Учебный портал на Flask. Регистрация, личный кабинет, теория и практика, импортируемые в базу материалы, поиск и защита административной панели.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -c "import secrets;print(secrets.token_urlsafe(48))"
# Подставьте выведенный секрет вместо шаблона SECRET_KEY в .env
flask --app app run
```

По умолчанию для локальной разработки используется SQLite (`instance/academy.db`). Для PostgreSQL задайте `DATABASE_URL`. На production включите HTTPS, `SESSION_COOKIE_SECURE=true` и WSGI-сервер. **Замените пароль БД из старой публичной версии config.py, если он использовался.**

## Отдельный вход администратора

Страница входа: `/admin/login`. При обращении к `/admin` без административной сессии открывается форма ввода логина и пароля. Обычная регистрация студента не даёт доступ к админке.

Создать или сменить единственную административную учётную запись можно только из консоли сервера:

```bash
flask --app app set-admin-login admin
```

Команда попросит дважды ввести новый пароль (ввод скрыт). Логин `admin` — пример, разрешён свой логин. Пароль должен содержать не менее 12 символов, заглавные и строчные буквы и цифру. **Не храните пароль в GitHub и не присылайте его в переписке.** В PostgreSQL/SQLite сохраняется только его хеш; повторное выполнение команды завершает прежние административные сессии. Сессия действительна не более четырёх часов.

В административной панели предусмотрена отдельная кнопка выхода. И открытие панели, и добавление, и удаление материала требуют административного входа. Новая таблица `admin_account` создаётся автоматически, старые записи и материалы остаются.

Перед публичным запуском обязательно включить HTTPS и `SESSION_COOKIE_SECURE=true`, добавить rate limiting попыток входа (например через Nginx/Redis) и выполнить резервное копирование базы.

## Прогресс

Ученик может самостоятельно отметить практику как выполненную; процент прогресса показывает долю отмеченных практик от числа практических материалов. Автопроверки решений пока нет.

## Безопасность

POST-формы имеют CSRF-токены, админские действия проверяют разрешения, размер загрузки ограничен 15 МБ и действует список разрешённых типов. Для публичного запуска также необходимы ограничения частоты запросов, проверка вложений антивирусом, HTTPS и аудит зависимостей.

Файлы, ранее загруженные в репозиторий, не удаляются простым добавлением .gitignore. Проверьте публичные архивы с личной информацией и историю Git.
